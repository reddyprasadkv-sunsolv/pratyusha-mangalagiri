## Angular implementation readiness

క్లయింట్ ఆమోదం తర్వాత ఈ కంటెంట్‌ను Angular typed modelsలో UIని మళ్లీ డిజైన్ చేయకుండా మ్యాప్ చేయవచ్చు:

- `HeroContent`: హీరో హెడ్డింగ్, సపోర్టింగ్ కాపీ, బాడీ, CTAలు, చిత్రం, స్టేటస్
- `ProductContent`: నాలుగు స్థిరమైన product IDs, bilingual copy, materials, sizes, price, stock, image, CTA, disclaimer, publication flag
- `RitualContent`: overviewతో పాటు delivery, frequency, duration, confirmation status ఉన్న inclusion records
- `BenefitContent`: claim-safe support points
- `ProcessStep`: క్రమంలో ఉన్న ఐదు journey steps
- `FounderContent`: approved biography, portrait, separately verified credentials
- `FAQContent`: approved answers లేదా unpublished pending questions
- `ContactContent`: optional verified contact and ordering fields; public placeholders ఉండవు
- `SeoContent`: title, description, H1, Open Graph content, image alt text
- `DisclaimerContent`: approval metadataతో matched English/Telugu disclaimer

English మరియు Teluguను `title_en`, `title_te`, `description_en`, `description_te`, `button_text_en`, `button_text_te`, `alt_text_en`, `alt_text_te` వంటి వేర్వేరు fieldsలో ఉంచాలి. Stable IDs మరియు approval states వల్ల తర్వాత Supabase నుంచి records లోడ్ చేసినా Angular presentation structure మార్చాల్సిన అవసరం లేదు. Step 3Bలో Supabase connection లేదా Angular code మార్పు లేదు.
